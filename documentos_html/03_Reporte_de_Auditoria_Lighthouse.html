PROBLEMAS IDENTIFICADOS

1. Deficiencias de Accesibilidad (A11y) y Contraste Insuficiente

  • Ausencia de etiquetas <label> asociadas explícitamente mediante for="id" a los inputs.
  • Falta de atributos ARIA (aria-required="true", aria-describedby) y roles para mensajes dinámicos.
  • Avisos de error y éxito sin role="status" ni aria-live="polite", siendo ignorados por lectores de pantalla.
  • Relación de contraste deficiente en botón deshabilitado (gris claro sobre blanco, 2.3:1), violando WCAG AA.

2. Ausencia de Metadatos SEO y Viewport Táctil Inadecuado

  • Omisión total de la etiqueta <meta name="description"> en el encabezado.
  • Carencia de directivas <meta name="robots"> y enlace canónico <link rel="canonical">.
  • Elementos interactivos con dimensiones táctiles inferiores al estándar recomendado de 48 x 48 píxeles.

3. Inexistencia de Arquitectura PWA y Service Worker

  • No existía manifest.json declarado en el <head> con display: standalone y tema de color.
  • Falta de iconos adaptativos en las resoluciones mínimas exigidas (192x192 y 512x512 píxeles maskable).
  • Ausencia de un Service Worker que intercepte peticiones en el evento fetch para disponibilidad offline.

3. Corrección 3: Despliegue de PWA, Web App Manifest y Service Worker

Archivos modificados: src/manifest.json, src/sw.js, src/app.js, src/index.html

self.addEventListener('fetch', (event) => {
  if (!event.request.url.startsWith('http')) return;
  event.respondWith(
    caches.match(event.request).then((cachedResponse) => {
      if (cachedResponse) return cachedResponse;
      return fetch(event.request).then((networkResponse) => {
        if (!networkResponse || networkResponse.status !== 200 || networkResponse.type !== 'basic') {
          return networkResponse;
        }
        const toCache = networkResponse.clone();
        caches.open(CACHE_NAME).then((cache) => cache.put(event.request, toCache));
        return networkResponse;
      }).catch(() => {
        if (event.request.mode === 'navigate') return caches.match('./index.html');
      });
    })
  );
});
