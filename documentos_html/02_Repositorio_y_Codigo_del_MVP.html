1. Estructura y Arquitectura del Repositorio

El repositorio oficial del proyecto ha sido organizado siguiendo el patrón de arquitectura limpia para aplicaciones web cliente (Frontend Vanilla), desacoplando estrictamente la estructura semántica (HTML5), las reglas de diseño y accesibilidad (CSS3), la lógica de negocio y validación del DOM (JavaScript ES6+) y la infraestructura de soporte Progressive Web App (Manifest y Service Worker).

El código prescinde totalmente de librerías externas o frameworks pesados (como React, Angular o Bootstrap), garantizando tiempos de carga casi instantáneos (First Contentful Paint < 0.5s), consumo mínimo de batería y cumplimiento de los más altos estándares de rendimiento y seguridad.

2.3. Archivo: src/app.js

document.addEventListener("DOMContentLoaded", () => {
  const form = document.getElementById("form-reporte");
  const inputDesc = document.getElementById("desc-reporte");
  const inputUbi = document.getElementById("ubicacion");
  const checkAnonimo = document.getElementById("anonimo");
  const btnEnviar = document.getElementById("btn-enviar");
  const mensajeExito = document.getElementById("mensaje-exito");
  const descError = document.getElementById("desc-error");
  const ubiError = document.getElementById("ubi-error");
  const contadorCaracteres = document.getElementById("contador-caracteres");

  inputDesc.addEventListener("input", () => {
    contadorCaracteres.textContent = `${inputDesc.value.length} / 300`;
    limpiarError(inputDesc, descError);
  });
  inputUbi.addEventListener("input", () => limpiarError(inputUbi, ubiError));

  function limpiarError(input, errEl) {
    input.classList.remove("campo-invalido");
    input.removeAttribute("aria-invalid");
    if (errEl) { errEl.textContent = ""; errEl.style.display = "none"; }
  }

  function marcarError(input, errEl, msg) {
    input.classList.add("campo-invalido");
    input.setAttribute("aria-invalid", "true");
    if (errEl) { errEl.textContent = msg; errEl.style.display = "block"; }
  }

  form.addEventListener("submit", (e) => {
    e.preventDefault();
    const descValor = inputDesc.value.trim();
    const ubiValor = inputUbi.value.trim();
    let esValido = true;

    if (descValor === "") {
      marcarError(inputDesc, descError, "La descripcion es obligatoria y no puede contener solo espacios.");
      esValido = false;
    }
    if (ubiValor === "") {
      marcarError(inputUbi, ubiError, "La ubicacion o referencia es obligatoria.");
      esValido = false;
    }
    if (!esValido) {
      if (descValor === "") inputDesc.focus(); else inputUbi.focus();
      return;
    }

    const reporte = {
      folio: "REP-" + Date.now().toString(36).toUpperCase(),
      descripcion: descValor,
      ubicacion: ubiValor,
      anonimo: checkAnonimo.checked,
      fechaCreacion: new Date().toISOString(),
      estado: "PENDIENTE_PERSISTENCIA"
    };
    console.log("Reporte empaquetado exitosamente:", reporte);

    btnEnviar.disabled = true;
    btnEnviar.textContent = "Enviando reporte...";
    mensajeExito.classList.remove("oculto");
    form.reset();
    contadorCaracteres.textContent = "0 / 300";

    setTimeout(() => {
      btnEnviar.disabled = false;
      btnEnviar.textContent = "Registrar Reporte Anonimo";
    }, 3000);

    setTimeout(() => mensajeExito.classList.add("oculto"), 4500);
  });

  if ("serviceWorker" in navigator) {
    window.addEventListener("load", () => {
      navigator.serviceWorker.register("./sw.js")
        .then(reg => console.log("[PWA] Service Worker registrado:", reg.scope))
        .catch(err => console.error("[PWA] Error en Service Worker:", err));
    });
  }
});

2.5. Archivo: src/sw.js

const CACHE_NAME = "reportes-urbanos-v1.0.0";
const STATIC_ASSETS = [
  "./",
  "./index.html",
  "./style.css",
  "./app.js",
  "./manifest.json",
  "./icons/icon-192.png",
  "./icons/icon-512.png"
];

self.addEventListener("install", (e) => {
  e.waitUntil(
    caches.open(CACHE_NAME)
      .then(cache => cache.addAll(STATIC_ASSETS))
      .then(() => self.skipWaiting())
  );
});

self.addEventListener("activate", (e) => {
  e.waitUntil(
    caches.keys().then(keys => {
      return Promise.all(keys.map(k => {
        if (k !== CACHE_NAME) return caches.delete(k);
      }));
    }).then(() => self.clients.claim())
  );
});

self.addEventListener("fetch", (e) => {
  if (!e.request.url.startsWith("http")) return;
  e.respondWith(
    caches.match(e.request).then(cached => {
      return cached || fetch(e.request).then(res => {
        if (!res || res.status !== 200 || res.type !== "basic") return res;
        const copy = res.clone();
        caches.open(CACHE_NAME).then(cache => cache.put(e.request, copy));
        return res;
      }).catch(() => {
        if (e.request.mode === "navigate") return caches.match("./index.html");
      });
    })
  );
});

3. Bitácora de Ingeniería de Prompts (Desarrollo Guiado con IA)

3.1. Prompt Inicial

Contexto: Estoy construyendo una PWA para que los ciudadanos reporten problemas urbanos.
Tecnologías: HTML5, CSS3 y JavaScript vanilla, sin frameworks ni librerías externas.
Requerimiento específico: Crea un formulario con un campo de texto para la descripción, un campo para la ubicación y un botón para enviar el reporte. Al hacer submit, se debe prevenir la recarga de página, validar que los datos no estén vacíos y mostrar el objeto empaquetado en la consola del navegador.
Restricciones: No usar frameworks, mantener código desacoplado en archivos separados y usar un diseño responsive básico.
Formato esperado: Entrega el código estructurado en index.html, style.css y app.js.

Evaluación crítica: La IA generó una estructura funcional básica. Sin embargo, la validación era ingenua (if (!desc)), permitiendo que pasaran campos con puros espacios, no existía feedback visual de confirmación y el botón permitía múltiples clics seguidos.

3.2. Prompt de Refinamiento

Contexto: Mejorando la robustez de la lógica de negocio de la PWA de Reportes Urbanos.
Tecnologías: JavaScript vanilla y CSS3.
Requerimiento específico: Modifica la validación del formulario en app.js y los estilos en style.css para:
1. Prevenir que se envíen campos con puros espacios vacíos usando el método .trim(). Si está vacío, resalta el campo con borde rojo y muestra un mensaje de error claro debajo del input.
2. Deshabilitar el botón de envío durante 3 segundos tras un envío exitoso para evitar que el usuario haga doble clic repetitivo, cambiando su texto temporalmente a "Enviando...".
3. Limpiar automáticamente los campos del formulario tras el envío exitoso mediante el método form.reset().
4. Mostrar una alerta visual de éxito destacada en color verde que se oculte automáticamente después de unos segundos.
Restricciones: Mantener estrictamente Vanilla JS, sin alertas bloqueantes alert() del navegador, asegurando accesibilidad.

Evaluación crítica: El código integró satisfactoriamente el método .trim(), el temporizador de 3000 ms con setTimeout(), el reseteo del formulario y las alertas accesibles.

3.3. Prompt de Arquitectura PWA y Calidad Técnica

Contexto: Preparar la PWA de Reportes Urbanos para una auditoría perfecta de 100/100 en Google Lighthouse.
Tecnologías: HTML5 semántico, CSS3 de alto contraste, Service Worker y Web App Manifest.
Requerimiento específico:
1. En index.html agrega meta description descriptiva, viewport adecuado, etiquetas de accesibilidad ARIA (aria-required, aria-describedby, role="status", aria-live="polite") y asocia todos los <label> a sus inputs.
